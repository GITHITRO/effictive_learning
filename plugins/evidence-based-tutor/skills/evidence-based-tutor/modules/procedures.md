# Модуль 2. Процедуры и алгоритмы

Для умений с правильным порядком шагов: решать задачи по математике и физике, писать код, считать, применять алгоритм. Каркас — **4C/ID** (d ≈ 0.79): целые задачи от простых к сложным, справочная информация по ходу, отдельная тренировка рутин.

| Методика | Суть | Когда / граница | Эффект |
| --- | --- | --- | --- |
| Worked examples + fading | Полный разбор → пропуски → задача с подсказками → сам | Для novice; у продвинутых теряет смысл | g ≈ 0.48 |
| Subgoal labels | Подписывать в примере цели шагов («сначала считаем …») | Готовые подписи лучше, чем придуманные учеником | малый–средний |
| Expertise reversal | Опору снимают по мере роста | Определяет режим (таблица ниже) | — |
| Productive failure | Задача до объяснения, потом разбор | Только при наличии базы; у младших хуже | g ≈ 0.36 |
| Deliberate practice | Задачи на краю умения, целевая точность 70–85% | Для proficient | 4–26% дисперсии |
| Part-task practice | Отработка рутин до скорости и точности | Синтаксис, базовые приёмы | — |
| Variable practice | Менять условия задачи | После уровня developing | d ≈ 0.2–0.4 |
| Interleaving задач | Смешивать типы задач, чтобы ученик выбирал метод | После первичного освоения каждого типа | g ≈ 0.34 (математика) |
| Step-based tutoring | Обратная связь на каждом шаге, а не только на ответе | Формат агента по умолчанию | d ≈ 0.76 |
| Transfer check | Задача в непривычном контексте | Перед повышением уровня | — |

| Уровень | Признак | Режим |
| --- | --- | --- |
| novice | < 50% без подсказок | Worked example с подписями целей шагов → похожая задача |
| developing | 50–85% | Примеры с пропусками, подсказки по запросу, fading |
| proficient | ≥ 85% | Productive failure, variable и deliberate practice, смешанные задачи |
| automated | быстро и без ошибок | Поддерживающие повторения, перенос |

Граница: после разобранного примера для сложных задач простой тест не лучше повторного изучения примера (van Gog 2015). Новичку давай ещё пример или задачу с подсказкой, а не голый тест.

Fading: снимай следующую опору только после двух верных решений на текущем уровне подсказки. Ошибка возвращает на шаг назад. Правило из шага давай вместе с причиной («почему два корня»), а не голым фактом.

Мастерство по компонентам можно оценивать моделью knowledge tracing (`pyBKT`, MIT), если есть журнал попыток; без неё — по accuracy_unassisted из профиля.

Источники: Barbieri 2023; Kalyuga 2007; Sinha & Kapur 2021; Costa 2021; Macnamara 2014; Brady 2004; Czyż 2024; Brunmair & Richter 2019; VanLehn 2011; Margulieux et al. 2016; van Gog et al. 2015.
