## Ход 2. Тьютор
Договорились, дальше учим с картинками 👍 Сравнивать тогда не получится, но картинка вместе со словом точно не вредит. Одна мелочь: с текстовых карточек ты в прошлый раз вспомнила 4 из 5, так что «ничего» это точно не было 😉

**Разбор повторения**

✅ **go → went → gone** и **see → saw → seen** — всё верно. Их повторим через неделю.

🔀 **write и ride:** вторые формы ты назвала правильно, а третьи поменялись местами. Ты сама заметила, что они слиплись: звучат похоже, и обе меняются по одной схеме (i → o → i + en). Разлепить их поможет буква, которая удваивается:

```
 ✍️  wriTe  →  wrote  →  wriTTen     T из wriTe → TT
 🚲  riDe   →  rode   →  riDDen      D из riDe  → DD
```

Буква в третьей форме берётся из самого глагола: если глагол с **T**, будет **TT**, если с **D**, будет **DD**.

🛍️ **bring → brought → brought.** Это семья глаголов на **-ought**, обе формы у них одинаковые:

```
 🛍️  buy    →  bought
 💭  think  →  thought
 ☕  bring  →  brought   ← «принесла кофе»
```

**Бонус.** *rode* — верно 🎉. *Bringed* — нет, правильно ***brought***: *I rode a bike and **brought** back three bags of coffee.* Хорошо, что ты сама засомневалась, это правильное чутьё.

## Ход 4. Тьютор
Хорошая разведка! *flew* и *took* ты угадала правильно 👏 Обе вторые формы верные. А третьи формы и *drink* устроены по-другому. Вот картинки:

```
 ✈️  fly    →  flew   →  flowN
 📸  take   →  took   →  takeN
```

Посмотри на третьи формы, которые ты уже знаешь: go**ne**, see**n**, writte**n**, ridde**n**, и теперь ещё flow**n** и take**n**. У многих неправильных глаголов третья форма кончается на **-n**. Поэтому если после *have* хочется сказать *-ed*, сначала попробуй **-n**.

```
 ☕ ☕ ☕   drInk  →  drAnk  →  drUnk
 полная   пьёшь     выпила     всё выпито
```

Здесь меняется только одна гласная: **i → a → u**. Буквы идут как по лесенке: **I** (сейчас), **A** (вчера), **U** (уже готово).

Твои предложения правильно:
- *I **flew** to Rome. I have never **flown** business class.* ✈️
- *I **drank** three espressos yesterday.* ☕☕☕
