### Три слова, на которых держится вся тема

**1. Квадратное уравнение** выглядит так:

```
 a·x²  +  b·x  +  c  = 0
 ↑         ↑       ↑
 при x²    при x   число без x
```

a, b, c называются **коэффициентами**. Главное условие: **a ≠ 0**, иначе x² пропадёт и уравнение перестанет быть квадратным.

В твоём уравнении x² − 5x + 6 = 0:
- a = 1 (перед x² ничего не написано, значит там 1);
- b = −5 (**знак берём вместе с числом!**);
- c = 6.

**2. Корень** — это число, которое при подстановке вместо x даёт 0. Ты это уже проверил: 2 и 3 — корни.

**3. Сколько корней:** у квадратного уравнения бывает **два, один или ни одного**. Больше двух не бывает.

Подбор работает только на удобных числах. Поэтому дальше мы выучим формулу, которая находит корни всегда.

### Главная формула: дискриминант

Это способ найти корни **любого** квадратного уравнения. Разберём его на уравнении, которое ты уже решил подбором, чтобы было видно, что формула даёт тот же ответ.

**x² − 5x + 6 = 0**

**Шаг 1. Выписать a, b, c**
a = 1, b = −5, c = 6

**Шаг 2. Посчитать дискриминант D = b² − 4ac**
D = (−5)² − 4·1·6 = 25 − 24 = **1**

**Шаг 3. По D понять, сколько корней**
- D > 0 → два корня
- D = 0 → один корень
- D < 0 → корней нет (стоп, решать дальше не нужно)

У нас D = 1 > 0, значит корней два.

**Шаг 4. Найти корни по формуле**

```
       −b ± √D
  x = ─────────
         2a
```

x = (5 ± 1) / 2 → x₁ = 6/2 = **3**, x₂ = 4/2 = **2**

Получились **2 и 3**, как и при подборе. 

Обрати внимание на **−b**: у нас b = −5, значит −b = 5. Минус на минус даёт плюс, ровно как в (−3)² из первого задания.

Правильная формула:
