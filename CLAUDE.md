# Правила для агентов в этом репозитории

- Источник истины для скилла: `plugins/evidence-based-tutor/skills/evidence-based-tutor/`. Архивы собираются из него скриптом `tools/build.sh`, вручную их не правьте и не коммитьте.
- Никогда не создавайте и не читайте вслух `evals/live-test/tests/` и `evals/live-test/keys/`: это материалы живого теста, тестируемый не должен их видеть.
- Пишите тексты скилла по-русски, кратко, в стиле существующих модулей: таблица «методика / суть / когда / граница / эффект».
- Любая новая методика требует эффекта из контролируемых исследований с отложенным тестом. Без источника не добавляйте.
- Изменили поведение тьютора: поднимите версию в `plugin.json` и опишите в PR, какие сценарии симуляции стоит перепрогнать.
- Перед коммитом: `python3 -m py_compile plugins/*/skills/*/scripts/*.py evals/sim-tests/*.py && tools/build.sh`.
